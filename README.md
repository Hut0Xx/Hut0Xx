## Sobre mí

Soy Técnico Superior en Desarrollo de Aplicaciones Web, con experiencia creando y mejorando soluciones para gestión de reservas, restauración, inmobiliaria y campañas comerciales.

Me interesa especialmente el desarrollo full-stack: transformar una necesidad real en una aplicación bien estructurada, segura, rápida y fácil de utilizar. Trabajo tanto en el frontend como en el backend, diseñando interfaces, APIs REST, modelos de datos, sistemas de autenticación y paneles de administración.

Actualmente continúo ampliando mi portfolio con proyectos completos que incluyen pruebas, documentación, contenedores y despliegue. Busco una oportunidad como **Desarrollador Web Junior**, **Frontend Developer**, **Backend Developer** o **Full Stack Developer**.
